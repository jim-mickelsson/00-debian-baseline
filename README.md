# Debian IaC Hardening Baseline

This repo will build a hardened Debian VM with Terraform and Ansible.

## Purpose

It will be used to create and harden new VMs Proxmox. This project is a way for me to learn more about Linux, hardening, Terraform, and Ansible.

## What it does

1. Terraform creates the VM on Proxmox (planned)
2. Ansible configures and hardens it (planned)

## Environment

Segmented Proxmox homelab, managed from a single dedicated admin host.
